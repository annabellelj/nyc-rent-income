About the data

Data. Income and rent are 2024 American Community Survey 5-Year estimates from the U.S. Census Bureau. The analysis uses Census ZIP Code Tabulation Areas (ZCTAs), which approximate USPS ZIP code service areas but are not identical to them.

Notes. Census values reported only as an upper category are shown with a “+”; the trend line uses exact estimates only. ZCTAs with unavailable estimates remain marked as “No estimate.” A small number of border ZCTAs were excluded because only a fraction of their geography falls within New York City.

Sources. U.S. Census Bureau (B19013, B25064); NYC Open Data ZIP Code Tabulation Areas; OpenStreetMap contributors.
